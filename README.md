# God Discord Bot

[Qiitaの記事「口下手なチームメイトを1日で教育した話」](https://qiita.com/Ets/items/4a0466843c8d98d74295)
の考え方を、現在のDiscord向けに作り直したローカル学習型Botです。
外部のAI APIへ会話を送信しません。

> [!IMPORTANT]
> このBotは、指定チャンネルの会話本文とDiscordの識別子をローカルの
> SQLiteへ保存します。導入前に参加者へ説明して同意を得てください。
> 業務・機密チャンネルでの利用は想定していません。

## 特徴

- 外部AI APIを使わず、学習・検索・応答をローカルで完結
- 保存対象を環境変数で指定した1サーバー・1チャンネルに限定
- 発言の編集・削除、本人による忘却、管理者による消去に対応
- Docker ComposeまたはPython 3.11以上で起動
- 天気、地震、計算、DNS、QRコードなどの補助コマンドを搭載

## 必要なもの

- Discord Bot Tokenと、Botを追加できるDiscordサーバー
- Docker Compose、またはPython 3.11以上
- 初回のDockerビルドまたはPythonパッケージ導入時のインターネット接続

## 何をするBotか

- 環境変数で固定した1サーバー・1チャンネルだけを学習
- チャンネルの人間の発言を時系列のままSQLiteへ保存
- 対象チャンネルでは全発言へ返答
- 同じサーバーの他チャンネルでは、メンションまたは設定語にだけ返答
- 他チャンネルの発言は学習せず、対象チャンネルの記憶を利用
- 発言末尾のひらがな6文字が似ている過去発言を探す
- その後5発言以内を「返事らしい発言」として選ぶ
- 過去の返事に含まれる名詞を、今回の入力にある名詞でランダム置換
- 見つからない時は学習済み発言をランダムに返す
- URL、コード、メールアドレス、APIキーらしい内容は学習しない
- 3文字以下または記号だけの発言は応答しても学習保存しない
- 通常・「だよ／だね」・「ござる」の口調を選択可能
- 元のDiscord発言の編集・削除を学習データへ反映
- 本人による忘却、管理者によるチャンネル単位の消去に対応
- `天気 <都市名>` で現在の天気、`calc <式>` で安全な四則計算に対応
- 起動時に「おはよう！」と日替わりラッキーアイテム、正常終了時に
  「おやすみー」と投稿
- 毎日23:25 JSTに就寝予告Embedを投稿し、23:30〜06:00は通常会話と
  学習を休止（便利コマンドは利用可能）

生成AIではないため、会話を大量に聞くまでは返答候補がありません。
記事のReudyと同じく、うまさよりも「コミュニティの言葉を覚えて真似る」
ことを狙ったBotです。

返答ロジックはReudyの中心部分を移植しています。意味理解、LLM、埋め込み検索は
使いません。末尾の形と単語だけで「理解したふり」をするため、会話として成立
しない返事も通常動作です。形態素解析はMeCabの代わりにローカル動作する
Janomeを使っています。

## セットアップ

最短で試す場合は、Discordアプリを作成したあと次を実行します。

```bash
cp .env.example .env
# .envにBot Token、サーバーID、チャンネルIDを設定
docker compose up -d --build
docker compose logs -f bot
```

### 1. Discordアプリを作る

1. [Discord Developer Portal](https://discord.com/developers/applications) で
   ApplicationとBotを作成
2. **Bot > Privileged Gateway Intents > Message Content Intent** を有効化
3. OAuth2 URL Generatorで `bot` と `applications.commands` を選択
4. Bot Permissionsで次を許可してサーバーへ招待
   - View Channels
   - Send Messages
   - Read Message History
5. Bot Tokenを取得

会話本文を学習するため、Message Content Intentは必須です。

### 2. 環境変数を設定する

```bash
cp .env.example .env
```

`.env` の `DISCORD_TOKEN`、`TARGET_GUILD_ID`、`TARGET_CHANNEL_ID` を
設定します。Botはこのサーバーとチャンネル以外のメッセージを保存せず、
対象サーバー外では返答もしません。スラッシュコマンドも対象サーバーだけへ
同期されます。

`BOT_PERSONA=casual` では「ですね→だね」「ですよ→だよ」
「ですか→なの？」のように発言直前で口調を変換します。元のReudy風の
出力をそのまま使う場合は `normal`、記事のような侍口調は `samurai` です。

SQLiteサーバーの構築や認証設定は不要です。`DATABASE_PATH` を省略すると
`data/memory.sqlite3` が自動作成されます。Docker利用時は
Composeのボリューム設定により、ホスト側の `./data` へ保存されます。

起動直後にも十分な返答候補があるよう、RealPersonaChatから変換した
約40万発話の日本語雑談コーパスを利用します。出典、変換内容、CC BY-SA 4.0
ライセンスは `corpus/README.md` に記載しています。`SEED_CORPUS_PATH` で
別ファイルへ差し替えられ、空にすると初期コーパスなしで起動します。
`SEED_CORPUS_WEIGHT=0.15` は、初期コーパスとDiscordの記憶の両方に候補が
ある時、初期コーパスを選ぶ確率を15%にします。Discord側に候補がなければ
初期コーパスへフォールバックします。
変換済みコーパスは、Discordの短いやり取りに向かない20文字超の発話を
収録しません。`MAX_REPLY_SOURCE_LENGTH=20` により、Discordから覚えた
長文も応答元には使わず、文中を機械的に切らずに短い発話をそのまま返します。
`RESPONSE_DRIFT_RATE=0.85` では、85%の確率で入力とのベクトル類似度が低い
学習済みの完成文を選びます。文章単体の形は保ちながら、会話としては意図的に
噛み合わない返答になります。残り15%は通常の会話近傍から返します。
`WORD_SPLICE_RATE=0.0` では通常会話の文の接ぎ木を無効にしています。
値を上げると、異なる学習発言をJanomeの
形態素境界で継ぎ合わせます。値を上げるほど、会話として成立しない変な
混成文が増えます。天気・計算の結果にはこの加工を適用しません。
`WORD_MUTATION_RATE=0.35` では、35%の確率で学習文中の名詞を最大2個、
ベクトル的に近い別の学習発言にある名詞へ差し替えます。動詞・助詞・語尾は
変えず、名詞の文法上の役割はあえて厳密に合わせません。そのため文の骨格を
おおむね保ちつつ、「気温したいです定番」のような概念の崩れも混ざります。
残りの応答では学習済みの完成文をそのまま使います。
`CUTE_TONE_RATE=0.35` では通常会話の35%に「だよ」「だね」「なのだ」
「にゃ」などの柔らかい語尾を付けます。「うにゃ〜」は低確率でだけ使い、
すでに「よ」「ね」で終わる文には足しません。天気・DNS・計算などの
コマンド結果は加工しません。

### 3-A. Dockerで起動する

```bash
docker compose up -d --build
docker compose logs -f bot
```

### 3-B. Pythonで起動する

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
set -a
source .env
set +a
god-bot
```

### 4. Discordで話す

起動後は対象チャンネルの会話を記憶しながら全発言へ応答します。同じ
サーバー内の他チャンネルでは、Botへのメンションまたは `TRIGGER_WORDS`
にだけ反応します。

便利機能は対象サーバー内なら対象外チャンネルでも利用でき、入力内容は
学習しません。

| 入力例 | 内容 |
|---|---|
| `help` | 利用できるコマンドをカテゴリ別に表示 |
| `status` | 神様の稼働時間・遅延・学習件数・DBサイズ |
| `pc` | ホストPCの負荷・メモリ・ディスク・稼働時間 |
| `unit 10 km mile` | 長さ・重さ・温度・容量・時間を変換 |
| `hash sha256 文字列` | SHA-256などのハッシュ値を計算 |
| `文字数 文章` | 文字数・空白除外・行数・UTF-8バイト数を表示 |
| `qr 文字列` | 文字列やURLからQRコード画像を生成 |
| `password 32` | 英大小文字・数字・記号入りのパスワードを生成 |
| `lisp (+ 1 (* 2 3))` | 安全なScheme風S式を評価 |
| `地震` | 気象庁防災情報XMLから最新の震源・震度情報を表示 |
| `アメダス 静岡県 気温` | 気象庁の観測値を地域別画像で表示（気温・降水・風・日照・湿度） |
| `名言` | 学習済みの短い発言から怪しい神託を生成 |
| `裁判 猫 犬` | 二者を学習単語で雑に裁く |
| `天気 東京` | Open-Meteoから現在の天気・気温・湿度などを取得 |
| `天気 浜松 明日` | 今日・明日・明後日の天気、気温、降水確率などを取得 |
| `天気 浜松 今週` | 今週または来週の予報を曜日ごとに表示 |
| `calc (12 + 3) * 4` | 四則演算、剰余、累乗、括弧を安全に計算 |
| `ping` | Botの応答確認とDiscord WebSocket遅延を表示 |
| `whois example.com` | RDAPでドメインの登録情報を表示 |
| `tls example.com` | TLS証明書の期限・発行者・接続方式を表示 |
| `ip 8.8.8.8` | RDAPで公開IPの割り当て情報を表示 |
| `roll 2d6` | サイコロの個別結果と合計を表示 |
| `choice ラーメン 寿司 カレー` | 候補からランダムに1つ選択 |
| `dns example.com` | A・AAAA・MXレコードを検索 |
| `おみくじ` | 学習単語を使った怪しい運勢を表示 |
| `連想 猫` | ベクトル的に近い学習単語を表示 |
| `要約 今日` | 今日の記憶件数・頻出語・雑な要約を表示 |

## コマンド

| コマンド | 権限 | 内容 |
|---|---|---|
| `/memory status` | 全員 | 学習状態と件数を表示 |
| `/memory forget-me` | 全員 | このサーバーで自分の記憶を削除 |
| `/memory purge` | サーバーの管理 | 現在のチャンネルの記憶を全削除 |

## プライバシー上の注意

- Botを追加する前に、会話がローカル保存されることをサーバーメンバーへ告知してください。
- データは `DATABASE_PATH` のSQLiteファイルに平文保存されます。ホストとバックアップのアクセス権を制限してください。
- 初期設定では起動時に90日を超えた発言を削除します。`MEMORY_RETENTION_DAYS=0` なら期限なしです。
- 対象チャンネルの既存データを消す場合は `/memory purge` を使います。
- 誤って機密情報を返す可能性はゼロではありません。業務・機密チャンネルでは有効化しないでください。
